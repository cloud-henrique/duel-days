# Duel Links portraits (uso pessoal)

Fonte: The Spriters Resource, seção Portraits de Yu-Gi-Oh! Duel Links.
Arte da Konami: não publique este conteúdo nem coloque em repositório público.

Estrutura: `<personagem>/full_charaNNN.png` (corpo inteiro 760x800),
`<personagem>/faces/charaNNN_II.png` (expressões, em geral 240x240; II = ordem do jogo),
`<personagem>/extras/` (cut-ins, telas de VS, nameplates e outros).
Zips de NPC com subpastas viram uma entrada por NPC (`<zip>__<npc>`).
Arquivos repetidos com o mesmo nome ganham sufixo `_altN`.
`manifest.json` lista tudo com dimensões.

Não baixados (sem link de download no site): Bakura (DSoD), Carly Carmine,
Carly Carmine (Dark Signer), Tour Guide From the Underworld,
Tristan Taylor (DSoD), Yugi Muto (DSoD), Z-one.
